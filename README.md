# NHDM-ASD

Source code associated with the manuscript:

**NHDM: A Novel Hybrid Deep Dyna-Q Model for Pre-emption of Autism**

## Dataset

The experiments use publicly available ABIDE-I and ABIDE-II datasets.

The datasets are not included in this repository. They can be accessed from their official repositories:

* ABIDE-I: https://fcon_1000.projects.nitrc.org/indi/abide/abide_I.html
* ABIDE-II: https://fcon_1000.projects.nitrc.org/indi/abide/abide_II.html

## Code

The repository contains the source code associated with the experimental framework, including feature selection, classification, DQN, Q-learning, and ensemble components.

## Reproducibility

The source code is provided to facilitate reproduction and further investigation of the experimental framework described in the associated manuscript.
Final Reproducible Implementation
The complete implementation corresponding to the revised manuscript is provided in NHDM_Final_Implementation.ipynb. The notebook contains the preprocessing, DMFO-based feature optimization, reliability-weighted ensemble classification, and Deep Dyna-Q based pre-emption workflow used in the revised study.
